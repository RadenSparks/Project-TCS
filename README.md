# TCS - EpicGames Clone

## Overview
This EpicGames Clone is a web-based platform designed to replicate the functionality and user experience of the Epic Games Store. This project aims to provide users with a seamless interface for purchasing, downloading, and managing their favorite games.

## Features
- **User Authentication**: Secure login and registration system.
- **Game Library**: Browse and search for games with detailed descriptions, screenshots, and trailers.
- **Shopping Cart**: Add games to your cart and proceed to checkout with various payment options.
- **Admin Page**: Admin Dashboard for mananging the site is also included.
- **Community Features**: User reviews, ratings, and forums for game discussions.

## Technologies Used
- **Frontend**: HTML, CSS, Bootstrap,
- **Backend**:  PHP 
- **Database**: MySQL
- **Payment Integration**: Paypal Sandbox
